# Restaurante App

## Autor
Gordon Ortega Henri Daniel

## Descripción

Sistema desarrollado en Python para administrar productos y usuarios de un restaurante utilizando Programación Orientada a Objetos.

## Estructura de datos utilizadas

### Lista (list)
Se utiliza para almacenar la colección de productos y usuarios.

### Tupla (tuple)
Se utiliza para representar las opciones fijas del menú principal.

### Diccionario (dict)
Se utiliza para relacionar cada opción del menú con su función correspondiente.

### Conjunto (set)
Se utiliza para obtener y mostrar categorías únicas de productos sin duplicados.

## Funcionalidades

- Registrar productos
- Buscar productos
- Actualizar productos
- Eliminar productos
- Listar productos
- Registrar usuarios
- Listar usuarios
- Mostrar categorías únicas
